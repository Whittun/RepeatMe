# Импорт из Obsidian

Нажмите **«Импорт из Obsidian»** в боковой панели. Подойдёт папка хранилища или обычная ZIP-копия с Markdown-файлами; SQL-дамп для этого не нужен.

1. Выберите папку или ZIP. Изначально ничего не отмечено. Скрытые папки настроек и вложения пропускаются.
2. Раскройте дерево и отметьте категории или отдельные заметки. Флажок категории выбирает всю ветку. **«Только эта ветка»** позволяет открыть нужную папку отдельно: она станет корневой категорией импорта. При переходе выбор сбрасывается.
3. Выберите категорию назначения в RepeatMe. Родительские категории для выбранных заметок создаются автоматически.
4. Проверьте имя Vault для ссылок `obsidian://`. Если загрузили только подпапку, укажите настоящее имя Vault и путь этой подпапки относительно корня хранилища. Для целого Vault путь оставьте пустым.
5. Включите импорт текста, только если хотите скопировать выбранный Markdown в материал карточки. По умолчанию переносятся названия, структура и ссылки. Вопросы для новых карточек не генерируются.
6. Нажмите **«Импортировать выбранное»**. После завершения появятся количества созданных и пропущенных записей.

Если ссылка на источник уже есть в базе либо название совпадает с карточкой в категории назначения, заметка пропускается. Существующие вопросы, материал, ссылки, расписание и история сохраняются. Импорт добавляет записи; он не синхронизирует, не удаляет и не переименовывает карточки, не изменяет файлы Vault.

Ограничения: до 1000 Markdown-заметок в источнике, до 1000 категорий за запрос, ZIP до 50 МБ. Для импорта текста выбранные файлы должны суммарно занимать до 1 МБ, каждая заметка — до 100 000 символов. При просмотре ZIP читаются имена, без распаковки текстов. На backend отправляется только выбранное содержимое. Выбор папки браузером не показывает полностью пустые каталоги; ZIP может содержать их отдельными записями.

`POST /api/imports/obsidian` принимает `{ vaultName, vaultPrefix?, basePath?, parentId?, folders: string[], notes: [{ path, content? }] }`. Пути задаются относительно загруженного источника. `basePath` — открытая отдельно ветка: её предки не создаются как категории, но исходные пути в ссылках сохраняются. Запись выполняется одной транзакцией с общей блокировкой изменений структуры.

Для обозначения импорта используется официальная иконка Obsidian без изменений. [Фирменная графика и правила Obsidian](https://obsidian.md/brand).
