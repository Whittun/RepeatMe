# Визуальное направление

RepeatMe использует пиксельный интерфейс: оранжевые акценты, тёмно-фиолетовую навигацию, тёплые светлые панели, квадратные индикаторы и кнопки с жёсткими тенями и эффектом нажатия. Направление — меню ретроконсолей и игровые инвентари.

## Референсы

- [NES.css](https://nostalgic-css.github.io/NES.css/): пиксельные рамки и объёмные кнопки.
- [SNES.css](https://snes-css.sadlative.com/): консольная типографика, панели и ограниченная палитра.

Это визуальные ориентиры. Приложение использует собственные CSS Modules, без подключения этих фреймворков.

## Графика и шрифты

- [Press Start 2P](https://github.com/google/fonts/tree/main/ofl/pressstart2p) — пиксельные заголовки и числа с поддержкой кириллицы. Сетка из 8 пикселей сохраняет аркадный характер и даёт больше деталей, чем прежний Tiny5. Размер заголовков — 16 или 24 пикселя, крупных счётчиков — 32 пикселя. Шрифт хранится локально в `apps/web/src/assets/fonts`; лицензия SIL Open Font License приложена в `OFL-PressStart2P.txt`. Небольшие подписи используют системный моноширинный шрифт.
- Основной текст, критерии и Markdown используют системный шрифт для удобства чтения. Код — моноширинный.
- `PixelIcons.tsx`, `PixelScene.tsx` и `public/favicon.svg` содержат оригинальную SVG-графику на единой пиксельной сетке.

Игровой стиль не добавляет уровни, XP, выдуманный прогресс и новые правила расписания. Статистика по-прежнему берётся с backend. Цвета состояний дополнены подписями и доступными описаниями. Настройка уменьшения движения отключает переходы.
